# Kreator sylwetki absolwenta fizyki

Statyczna aplikacja pozwalająca wybrać przedmioty z bloków programowych, opisać profil absolwenta i wygenerować graficzne drzewko kompetencji oraz zapis tekstowy do skopiowania.

## Uruchomienie

Otwórz stronę przez lokalny serwer HTTP:

```bash
python3 -m http.server 8000
```

Następnie przejdź na `http://localhost:8000`.

## Testy

```bash
npm test
```

## Technologie

- HTML
- CSS
- JavaScript (ES modules)
- Node.js test runner (tylko testy)
